Labels in a post (exploring interactions)

Four prototypes of the labels section on an evaluation post, made to answer one question: is it better to resolve label changes in place on the page, or inside a modal? Plus the admin where the label catalogue itself is managed. Each is a working page, not a mockup.

adm v2 Labels and categories, the admin — v2 The admin after the first round of feedback: posts are listed like the Violations page, known by their picture rather than a caption, and categories are deleted one at a time. New → adm v1 Labels and categories, the admin — v1 Where the catalogue is managed, laid out like Keyword Groups: search, create in bulk, rename, move, duplicate, merge, delete and export — with every change showing which posts it touches before it happens. → v4 Save and create, in place v3’s winning candidate on its own, with the ability to create new labels — and, via “Category / New label”, new categories — restored to the same in-place combobox. Current — used in interviews → v3 Save flow — in place vs modal The two candidates side by side. A resolves every action on the page; B resolves everything inside an “Edit labels” modal.
